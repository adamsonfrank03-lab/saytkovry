# Архитектура решения «RUG AI»

Этот проект демонстрирует два уровня интеграции ковров в интерьер клиента:

## 1. Клиентский интерактивный режим (Frontend-only)
Этот режим работает мгновенно в браузере без обращения к серверу.
*   **Метод**: Использование CSS 3D Transforms и Perspective.
*   **Реализм**: Применение `mix-blend-mode: multiply` позволяет ковру "впитывать" тени и текстуру оригинального пола под ним.
*   **Контроль**: Пользователь может вручную подстроить перспективу и положение ковра под свою фотографию.

## 2. AI Inpainting Pro (Backend-driven)
Продвинутый режим для максимально фотореалистичного результата.
*   **Модели**: Google Gemini (анализ геометрии) + Imagen 3 (инпайнтинг).
*   **Процесс**:
    1. Пользователь нажимает "Улучшить через ИИ".
    2. Фото комнаты и выбранный ковер отправляются на Flask-сервер.
    3. ИИ генерирует финальное изображение, где ворс ковра, освещение и контакты с мебелью просчитаны на уровне пикселей.

## Структура проекта
*   `public/`: Фронтенд-демо (HTML, CSS, JS).
*   `server/`: Бекенд на Flask для интеграции с Vertex AI.
*   `public/assets/`: Ваши ковры (`carpet1.jpg`, `carpet2.jpg`, `carpet3.jpg`).

## Как запустить
1. Откройте `public/index.html` в любом браузере для мгновенного демо.
2. Для серверной части: `python3 server/main.py` (требуется установка Flask).
