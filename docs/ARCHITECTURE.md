# Архитектура системы «AI-Примерка Ковров»

Этот документ описывает техническую реализацию функции виртуальной примерки ковров в интерьере клиента с использованием современных AI-моделей (Google Gemini и Imagen 3).

## 1. Технологический стек

*   **Frontend**: HTML5/JS (интерфейс загрузки и галерея результатов).
*   **Backend**: Python (Flask) + CORS для связи с фронтендом.
*   **AI Модели (Google Cloud Vertex AI)**:
    *   **Gemini 1.5 Flash**: Используется для визуального анализа комнаты, определения типа покрытия пола и генерации маски (полигона) для укладки ковра.
    *   **Imagen 3 (Product Placement)**: Используется для генерации финального изображения, где текстура вашего ковра накладывается на маску с учетом теней, освещения и перспективы.

## 2. Алгоритм работы (Backend)

Код в `server/main.py` организован следующим образом:
1.  Принимает изображение через POST `/api/process-carpet`.
2.  Вызывает функцию `get_carpet_variations`, которая в продакшене должна обращаться к Vertex AI.
3.  Возвращает список из 3-х вариантов генерации для выбора пользователем.

## 3. Интеграция с реальным API

Для активации реального ИИ:
1.  Установите библиотеки: `pip install google-cloud-aiplatform google-generativeai`.
2.  Настройте аутентификацию GCP (`gcloud auth application-default login`).
3.  В `server/main.py` укажите ваш `PROJECT_ID`.
4.  Раскомментируйте логику вызова моделей в `get_carpet_variations`.

## 4. Как запустить

### Запуск Backend (API)
```bash
cd server
export GCP_PROJECT_ID="vash-proekt"
python3 main.py
```

### Запуск Frontend
Просто откройте `public/index.html` в браузере. Фронтенд настроен на общение с бекендом по адресу `http://localhost:5000`.

## 5. Особенности реализации
*   **3 Варианта**: Система возвращает массив вариантов, что позволяет клиенту сравнить разные стили в одном интерьере.
*   **CORS**: Бекенд настроен на прием запросов с любого домена (для удобства разработки).
*   **Perspective**: Для достижения "красивого" результата Imagen 3 использует маску пола, что исключает эффект "наклеенного ковра".
